# 💊 Med Consult – Medicine Recommendation System

## 📖 Overview

**Med Consult** is a Medicine Recommendation System designed to suggest appropriate medications based on the user’s symptoms and medical history. Unlike AI-driven systems, Med Consult retrieves suggestions from a structured **predefined database** that includes details on:

- Diseases & Descriptions  
- Medications  
- Precautions  
- Workouts  
- Diet Plans  

The system maps user-reported symptoms to known clinical data and provides relevant recommendations, aiming to assist healthcare decision-making in a fast, efficient, and reliable manner.

---

## 🚀 Features

- 🧾 Symptom-based medicine recommendation  
- 📋 Disease descriptions & suggested precautions  
- 💊 Medication, workout, and diet suggestions  
- 🗂 Uses rule-based matching from a curated medical dataset  
- 🧠 Lightweight and non-AI driven – ensures fast and controlled outputs
