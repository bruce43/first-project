# MEDICINE RECOMMENDATION SYSTEM

=> What is Med consult?

  A Medicine Recommendation System is a software tool that suggests medicines based on user symptoms and medical history.
  It retrieves information from a pre-defined database containing disease, description, precaution, medication, workouts and diets.
  The system matches symptoms to appropriate medications using stored clinical data and rules.
  Its goal is to support healthcare decisions by providing quick, reliable, and relevant medicine suggestions.

=> Tools and Technologies used:

  Frontend – Python, HTML, CSS, JavaScript 
  Libraries – NumPy, Pandas 
  Text Editor – Jupyter Notebook, Android Studio
